# My Learning Journey - Web Development Project

This repository contains a structured HTML web page designed to demonstrate the fundamental building blocks of web development, focusing heavily on text formatting, semantic structures, and various types of lists.

## Project Structure
* **index.html**: The main entry point containing the full structural markup, styling elements, and student information sections.

## Key Concepts Demonstrated
The project acts as a functional showcase for the following core HTML features:

### 1. Document Architecture
* Uses the modern HTML5 `<!DOCTYPE html>` declaration.
* Leverages proper structure dividing metadata elements in `<head>` from the visual document workspace within `<body>`.

### 2. Standard and Semantic Elements
* **Typography:** Integrates distinct header tiers (`<h2>`, `<h4>`) to lay out clear informational hierarchies, combined with structural `<p>` text blocks.
* **Inline Formatting:** Applies `<b>` elements to bold specific text markers for enhanced visibility, alongside `<br>` tags to establish controlled linebreaks.
* **Semantic Footer:** Encloses operational metadata (Student details) strictly inside a native structural `<footer>` section.

### 3. List Variations
* **Unordered Lists (`<ul>`):** Displays a non-sequential, bulleted register tracking major back-end and scripting programming languages.
* **Ordered Lists (`<ol>`):** Outlines a progressive, step-by-step roadmap demonstrating the production timeline required to draft, style, and launch websites.
* **Nested / Mixed Lists:** Demonstrates structural inheritance by nesting core academic subject matters inside multi-tier list arrangements.
